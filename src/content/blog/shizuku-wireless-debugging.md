Android নিয়ে সিরিয়াস ঘাঁটাঘাঁটি করতে চাইলে প্রথম যে অ্যাপটা লাগবে, সেটা **Shizuku**। রুট ছাড়াই এটা তোমাকে সিস্টেম API ব্যবহারের অনুমতি দেয় — মানে এমন অনেক কাজ, যা আগে শুধু PC-তে ADB দিয়ে করা যেত, এখন ফোনেই করা যায়। Canta দিয়ে ডিব্লোট, App Ops দিয়ে পারমিশন কন্ট্রোল — সব Shizuku-র ওপর দাঁড়িয়ে।

## যা যা লাগবে

- Android 11 বা তার পরের ভার্সন (ওয়্যারলেস ডিবাগিং-এর জন্য)
- Shizuku অ্যাপ (GitHub বা Play Store থেকে)
- ফোন আর (প্রথমবার) একই Wi-Fi — না, PC লাগবে না!

## ধাপে ধাপে সেটআপ

**১. Developer options চালু করো:** Settings → About phone → Build number-এ ৭ বার ট্যাপ।

**২. Wireless debugging চালু করো:** Settings → System → Developer options → **Wireless debugging** অন করো।

**৩. Shizuku-তে Pairing:** Shizuku অ্যাপ খোলো → "Pairing" → "Notification options"-এ ট্যাপ করলে Wireless debugging-এর **Pair device with pairing code** অপশনে নিয়ে যাবে। ৬ সংখ্যার কোডটা Shizuku-তে বসাও।

**৪. Shizuku চালু করো:** অ্যাপে ফিরে এসে **Start** চাপ দাও। "Shizuku is running" দেখালেই কাজ শেষ!

## মনে রাখার মতো টিপস

- ফোন **রিস্টার্ট** হলে Shizuku বন্ধ হয়ে যায় — আবার শুধু Start চাপলেই হয় (পেয়ারিং সাধারণত মনে থাকে)।
- Wi-Fi বদলালে বা Wireless debugging অফ হয়ে গেলে আবার পেয়ার করতে হতে পারে।
- Shizuku নিজে কিছু করে না — এটা শুধু **দরজা খুলে দেয়**। আসল কাজ করে Canta, App Ops-এর মতো অ্যাপ।
- অচেনা অ্যাপকে Shizuku পারমিশন দেওয়ার আগে দুবার ভাবো — এটা পাওয়ারফুল জিনিস।

একবার সেটআপ হয়ে গেলে তুমি PC ছাড়াই ফোনেই "ডেভেলপার" হয়ে গেলে। পরের পোস্টে দেখবো এই পাওয়ার দিয়ে কীভাবে ফোনের জঞ্জাল সাফ করা যায়। 🧪
