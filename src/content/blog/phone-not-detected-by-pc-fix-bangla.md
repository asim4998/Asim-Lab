USB কেবল দিয়ে ফোন পিসিতে লাগালে, অথচ পিসিতে ফোনের কোনো খোঁজ নেই — **পিসিতে ফোন কানেক্ট হচ্ছে না** এমন অবস্থায় পড়োনি, এমন Android ব্যবহারকারী কমই আছে। কখনো শুধু চার্জ হয় কিন্তু ফাইল ট্রান্সফার হয় না, কখনো আবার `adb devices` কমান্ডে `unauthorized` বা `no devices/emulators found` লেখা ভেসে ওঠে। প্রথমবার হলে মনে হয় ফোনের পোর্টটাই বুঝি নষ্ট হয়ে গেছে।

ভয় পেয়ো না। বেশিরভাগ ক্ষেত্রে এটা কেবল, সেটিং বা ড্রাইভারের ছোট্ট একটা সমস্যা। এই পোস্টে দেখবো কেন এমন হয়, আর প্রতিটা কারণের ধাপে ধাপে সমাধান। শেষ পর্যন্ত পড়লে পিসি-ফোন কানেকশনের প্রায় সব সমস্যার উত্তর এখানেই পেয়ে যাবে।

## কেন পিসিতে ফোন কানেক্ট হচ্ছে না: আসল কারণগুলো

সমাধানে যাওয়ার আগে বুঝে নিই ভেতরে আসলে কী ঘটছে। ফোন পিসিতে লাগালে দুটো আলাদা জিনিস কাজ করে:

- **MTP (ফাইল ট্রান্সফার)** — ছবি, ভিডিও, ফাইল কপি করার পথ। এটা নির্ভর করে USB কেবল, ফোনের USB মোড সেটিং আর পিসির ড্রাইভারের উপর।
- **ADB (Android Debug Bridge)** — Shizuku, ডিব্লোটিং বা অ্যাপ ডেভেলপমেন্টের কাজে লাগে। এটা নির্ভর করে USB debugging সেটিং আর ফোনের authorization-এর উপর।

দুটোর সমস্যার লক্ষণ আলাদা, কারণও আলাদা। একে একে সবগুলো দেখি।

## ধাপ ১: কেবলটা আগে যাচাই করো (সবচেয়ে কমন কারণ)

শুনতে হাস্যকর লাগলেও, এই সমস্যার এক নম্বর কারণ হলো **চার্জিং-অনলি কেবল**। বাজারের অনেক সস্তা কেবলে ভেতরে শুধু চার্জিংয়ের তার থাকে, ডেটা ট্রান্সফারের তারই থাকে না। এমন কেবলে ফোন চার্জ হবে ঠিকই, কিন্তু পিসি ফোনকে চিনতেই পারবে না।

যাচাই করার সহজ উপায়: অন্য একটা কেবল দিয়ে চেষ্টা করো — বিশেষ করে ফোনের বক্সের সাথে আসা অরিজিনাল কেবলটা। অরিজিনাল কেবলে সাথে সাথেই ফোন পিসিতে শো করলে বুঝবে আগের কেবলটাই দোষী। কেবল বদলানোর পরও না হলে পরের ধাপে যাও।

## ধাপ ২: ফোনে USB মোড বদলাও

ফোন পিসিতে লাগানোর পরও যদি কিছু না হয়, নোটিফিকেশন প্যানেলটা নিচে টানো। সাধারণত **"Charging this device via USB"** বা **"USB charging"** নামে একটা নোটিফিকেশন আসে। এটাতে ট্যাপ করলে **USB preferences** পেজ খুলবে।

এখানে **"Use USB for"** সেকশনে **File transfer / Android Auto** সিলেক্ট করো। ডিফল্টভাবে অনেক ফোনে "No data transfer" বা "Charging only" সিলেক্ট থাকে — এটাই থাকলে পিসিতে ফোন শো করবে না, এটাই স্বাভাবিক।

নোটিফিকেশনটা না এলে: **Settings → Connected devices → USB** (কিছু ফোনে **Settings → System → USB preferences**)-এ গিয়ে একই অপশন পাবে। এই সেটিং বদলানোর সাথে সাথেই পিসিতে ফোনের স্টোরেজ দেখা যাওয়া উচিত।

## ধাপ ৩: পিসির ড্রাইভার ঠিক করো (Windows)

কেবল আর USB মোড ঠিক থাকার পরও ফোন না এলে দোষটা পিসির ড্রাইভারে। Windows-এ করণীয়:

1. ফোন পিসিতে লাগানো অবস্থায় **Device Manager** খোলো (Start মেনুতে "Device Manager" লিখে সার্চ দিলেই আসবে)।
2. **Portable Devices** বা **Other devices** সেকশনে তোমার ফোনের নামের পাশে হলুদ বিস্ময়চিহ্ন (!) আছে কিনা দেখো। থাকলে ড্রাইভার সমস্যা নিশ্চিত।
3. ফোনের নামে রাইট-ক্লিক করে **Update driver → Search automatically for drivers** দাও।

এতেও না হলে ফোন প্রস্তুতকারকের অফিসিয়াল USB ড্রাইভার ইনস্টল করো — Samsung-এর জন্য Samsung USB Driver, Xiaomi-র জন্য Mi USB Driver। জেনেরিক "MTP USB Device" ড্রাইভার অনেক সময় ঠিকমতো কাজ করে না। ড্রাইভার ইনস্টলের পর পিসি একবার রিস্টার্ট দিতে ভুলো না।

## ধাপ ৪: ADB-তে "unauthorized" এররের সমাধান

ফাইল ট্রান্সফার ঠিক আছে, কিন্তু `adb devices` দিলে ডিভাইসের পাশে **unauthorized** লেখা — এটা ADB ব্যবহারকারীদের সবচেয়ে পরিচিত এরর। এর মানে: পিসি ফোনকে চিনেছে, কিন্তু ফোন এখনো পিসিকে বিশ্বাস করেনি।

প্রথমে ফোনে **Developer options** চালু আছে কিনা দেখো (Settings → About phone → Build number-এ ৭ বার ট্যাপ)। তারপর:

1. **Settings → System → Developer options**-এ গিয়ে **USB debugging** অন করো।
2. একই পেজে **"Revoke USB debugging authorizations"**-এ ট্যাপ করো — পুরনো ভুল authorization মুছে যাবে।
3. ফোনটা খুলে কেবল লাগাও। এবার ফোনের স্ক্রিনে **"Allow USB debugging?"** ডায়ালগ আসবে, সাথে পিসির RSA fingerprint দেখাবে।
4. **"Always allow from this computer"**-এ টিক দিয়ে **Allow** চাপো।

ব্যস। এবার পিসিতে `adb devices` দিলে ডিভাইসের পাশে **device** লেখা আসবে। মনে রেখো — ডায়ালগটা ফোনের স্ক্রিন **অন** থাকা অবস্থায় আসে। স্ক্রিন বন্ধ থাকলে ডায়ালগ দেখতে পাবে না, আর ADB চিরকাল unauthorized-ই থেকে যাবে। এটাই সবচেয়ে বেশি মানুষের ভুল হয়।

## ধাপ ৫: ADB-তে ডিভাইস একদমই না দেখালে

`adb devices` লিস্ট পুরো খালি এলে:

- **platform-tools আপডেট করো** — পুরনো ADB ভার্সন নতুন Android চিনতে পারে না। Google-এর অফিসিয়াল platform-tools ডাউনলোড করে নতুন ফোল্ডার থেকে `adb` চালাও।
- **অন্য USB পোর্টে লাগাও** — পিসির সামনের পোর্টগুলো অনেক সময় পাওয়ার কম দেয়; পেছনের (মাদারবোর্ডের সরাসরি) পোর্টে লাগিয়ে দেখো।
- **USB 2.0 পোর্টে চেষ্টা করো** — কিছু পুরনো ফোন USB 3.0 পোর্টে ADB হ্যান্ডশেকে গোলমাল করে।
- `adb kill-server` দিয়ে `adb start-server` চালিয়ে ADB সার্ভার রিস্টার্ট দাও।

## ধাপ ৬: Linux ব্যবহারকারীদের জন্য

Linux-এ `adb devices` খালি এলে ৯৯% ক্ষেত্রে দোষ **udev rules**-এর। টার্মিনালে:

```
sudo adb kill-server
sudo adb start-server
adb devices
```

`sudo` দিয়ে একবার চালালে ডিভাইস দেখা গেলে বুঝবে পারমিশন সমস্যা। স্থায়ী সমাধান: `/etc/udev/rules.d/51-android.rules` ফাইলে তোমার ফোনের vendor ID দিয়ে rule যোগ করা। Vendor ID জানতে ফোন লাগানো অবস্থায় `lsusb` কমান্ড দাও — যেমন Samsung-এর জন্য `04e8`।

## বিকল্প: Wireless ADB (কেবল ছাড়াই)

কেবল নিয়ে আর ঝামেলা করতে না চাইলে wireless ADB ব্যবহার করো। ফোন আর পিসি একই WiFi-তে থাকতে হবে:

1. Developer options-এ **Wireless debugging** অন করো।
2. **"Pair device with pairing code"**-এ ট্যাপ করলে IP, পোর্ট আর ৬ সংখ্যার কোড দেখাবে।
3. পিসিতে: `adb pair <IP>:<port>`, কোড দাও, তারপর `adb connect <IP>:<আরেকটা পোর্ট>`।

একবার পেয়ার হয়ে গেলে পরে শুধু `adb connect` দিলেই চলে। Shizuku-ও এই একই wireless debugging পদ্ধতি ব্যবহার করে, তাই Shizuku চালাও যারা — এই ধাপগুলো তাদের চেনা লাগবে।

## ⚠️ একটা জরুরি সতর্কতা

কাজ শেষ হলে **USB debugging বন্ধ করে দাও**, বিশেষ করে পাবলিক বা অচেনা পিসিতে ফোন লাগানোর আগে। USB debugging চালু থাকা ফোনে কেউ ADB দিয়ে তোমার অজান্তে অ্যাপ ইনস্টল, ডেটা পড়া — অনেক কিছুই করতে পারে। Developer options থেকে এক ট্যাপে বন্ধ করা যায়, অভ্যাস করে ফেলো।

## সাধারণ প্রশ্ন

**ফোন চার্জ হচ্ছে কিন্তু পিসিতে শো করছে না কেন?**
প্রায় সবসময় কারণ চার্জিং-অনলি কেবল, নয়তো ফোনের USB preferences-এ "No data transfer" সিলেক্ট আছে। ধাপ ১ ও ২ দেখো।

**"Allow USB debugging?" ডায়ালগ আসছে না কেন?**
ফোনের স্ক্রিন অন রেখে কেবল লাগাও। না এলে Developer options থেকে "Revoke USB debugging authorizations" করে আবার চেষ্টা করো।

**adb devices-এ unauthorized থেকে device হচ্ছে না?**
ডায়ালগে Allow চাপার পরও না হলে `adb kill-server` → `adb start-server` → কেবল খুলে আবার লাগাও। পিসির RSA key বদলে গেলে (যেমন Windows রিইনস্টল) পুরনো authorization কাজ করে না — revoke করে নতুন করে Allow দিতে হয়।

**MTP-তে ফোন শো করে কিন্তু ফাইল কপি হয় না?**
বড় ফাইল (৪ GB+) কপি করতে গেলে FAT32 ফরম্যাটের পেনড্রাইভ-জাতীয় সীমাবদ্ধতা থাকে না ফোনে, কিন্তু MTP নিজেই বড় ফাইলে মাঝে মাঝে আটকে যায়। তখন ফাইলটা ভাগ করে কপি করো, বা wireless ADB/FTP দিয়ে পাঠাও।

**একই কেবলে অন্য ফোন চলে, আমারটা চলে না কেন?**
তোমার ফোনের USB পোর্টে ময়লা জমে থাকতে পারে — বন্ধ ফোনে শুকনো টুথব্রাশ দিয়ে আলতো করে পরিষ্কার করো। পোর্ট ঢিলা হয়ে গেলেও এমন হয়, তখন সার্ভিসিং লাগবে।
